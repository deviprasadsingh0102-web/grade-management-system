# Grade Management System

## Description
This project is a Grade Management System developed in Java.
It stores student marks, calculates averages, assigns grades, and generates reports.

## Features
- Add student marks
- View all students
- Calculate averages
- Assign grades (A, B, C, D, F)
- Generate performance reports

## Technologies Used
- Java
- Arrays
- Scanner
- Control Flow (loops, switch-case)

## How to Run
1. Open in NetBeans / VS Code
2. Compile the program
3. Run GradeManagementSystem.java
4. Follow menu options
